# תיקיית demo

התיקייה הזו קיימת אך ורק בשביל הדמו החי ב-GitHub Pages, והיא לא חלק מהאפליקציה עצמה.

האפליקציה האמיתית מדברת מול API נפרד: בפיתוח דרך `proxy.conf.json`, ובענן דרך הכתובת שב-`src/app/config.ts`.

ב-GitHub Pages מוגשים קבצים סטטיים בלבד, אין שרת, ולכן מסך ההתחברות נתקע ואף מסך לא נטען.

הפתרון: `demo/demo-backend.interceptor.ts` הוא HttpInterceptor שעונה לאותן קריאות עצמן מתוך הדפדפן.

בזמן הבנייה הוא מועתק ל-`src/app/`, ו-`demo/app.config.demo.ts` מועתק על `src/app/app.config.ts` כדי לרשום אותו.

הנתונים נשמרים ב-localStorage תחת המפתח `taskman-demo-db`, כך שיצירה, עדכון ומחיקה שורדים רענון של הדף.

כל אימייל וסיסמה מתקבלים במסך ההתחברות (למשל demo@demo.com וסיסמה בת שש תווים ומעלה), כדי שאף אחד לא ייתקע בשער.

לאיפוס הדמו לנתוני ההתחלה: להריץ `__resetDemo()` בקונסולה של הדפדפן ולרענן.

אף קובץ מקור קיים לא שונה - הכל נעשה בהעתקה בזמן ה-build.
